# 汇图壁纸网前端改造设计

**状态：** 等待用户确认设计稿  
**日期：** 2026-11-21

## 目标

把当前鱼皮云图库前端重塑为“汇图壁纸网”，让公开图库成为清楚、好逛、以壁纸图片为主角的体验，同时让登录后的空间、批量编辑、分析和管理页面拥有统一且易读的工作界面。改造覆盖整个前端视觉层，不改变服务端接口、数据结构和已有业务权限。

## 当前形态

- 技术栈为 Vue 3、TypeScript、Ant Design Vue 与 Vue Router。
- 当前公共页面和登录后页面共用顶栏、侧栏与固定页脚；公开首页主要是搜索框、分类标签和图片列表。
- 图片详情、上传/批量导入、个人/团队空间、分析、会员兑换和管理员表格各自有局部样式，整体仍沿用 Ant Design 默认外观。
- 前端可见旧品牌包含浏览器标题、顶部名称、登录/注册标题、页脚、编程导航链接和旧图标；分享链接组件也有旧域名默认值。

## 目标与边界

### 目标

- 使用“汇图壁纸网”作为唯一前端产品名称，提供新的品牌图标、页面标题、描述和 favicon。
- 重做公开画廊、详情、登录/注册、上传、空间、批量处理、分析及管理员页面的排版和视觉样式。
- 建立共享颜色、字体、间距、控件和响应式规则，确保首页之外的工作页面也属于同一产品。
- 保留现有 API 调用、路由、权限判断、表单字段和图片数据；重做空状态、加载状态和错误反馈的视觉呈现。
- 桌面与手机宽度均可用，键盘焦点清楚，尊重减少动态效果的系统设置。

### 不在本次范围

- 不修改后端接口、数据库或 COS 文件结构。
- 不改变空间权限、图片审核、扩图、搜图和批量操作的业务规则。
- 不使用虚构壁纸或测试图片填充页面；图库只展示服务端返回的真实内容，空库显示品牌化空状态。
- 不重命名 Java 包、API 路径或后端模块目录；本次去品牌限于前端产品表面、前端说明与前端包名。

### 防止的结果

- 不保留旧品牌名称、旧图标、旧产品链接或指向旧品牌域名的默认分享地址。
- 不把管理表格和空间工具也改成难以阅读的沉浸式图片页。
- 不用每页一套颜色与按钮，或用只适配桌面的大图布局。

## 方案比较

### 采用：影集画廊

将首页设计成安静、明亮的壁纸画廊：品牌导航紧凑，搜索是首页的主入口，真实精选图片组成不规则但有秩序的瀑布墙。详情页突出大图与下载/分享操作。工作区使用相同颜色和控件，但维持清晰的导航、表格与表单结构。该方案最适合同时承载公共浏览与现有云图库管理功能。

### 未采用：暗场沉浸

深色全屏画布能强化图片对比，但会让空间配额、管理员表格和上传表单长期处于较重的暗色界面，影响日常管理阅读。

### 未采用：蓝晒图谱

纸白与靛蓝的画册式排版很适合浏览和阅读，但作为贯穿工作区、分析图表和管理表格的系统视觉，编辑感会压过操作效率。

## 视觉规范

以下为本设计稿提出的具体实现值，完成后统一收敛到共享 CSS 变量：

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| 雾灰 | `#F3F5F2` | 页面外层背景 |
| 画纸白 | `#FFFFFF` | 图片卡、表单与工具面板 |
| 墨蓝 | `#17252D` | 主文字、深色品牌图形 |
| 海图蓝 | `#315FE8` | 主操作、链接、选中状态 |
| 朱橙 | `#E66B4E` | 收藏/强调状态与少量品牌点色 |
| 雾线 | `#DCE3E3` | 分隔线、边框、静态控件轮廓 |

- **标题字体：** `Songti SC` / `STSong` / `Noto Serif CJK SC` / 系统衬线回退；仅用于首页主标题和少量页面标题。
- **界面字体：** `PingFang SC` / `Noto Sans SC` / `Microsoft YaHei` / 系统无衬线回退；用于表单、导航、说明与正文。
- **图标：** 本地 SVG“汇图框”：四块错位画幅在中心汇成 H 形；小尺寸仍清晰，不依赖外部图片或在线字体。
- **圆角与阴影：** 图片卡片使用中等圆角和轻阴影；数据表格、筛选工具保持较小圆角和轻边线。
- **动效：** 图片悬停轻微抬升和缩放，导航/筛选状态短过渡；不做自动轮播或持续背景动画。

## 页面结构

### 公开图库

```text
┌ 汇图图标  汇图壁纸网     分类/专题/上传入口             登录/头像 ┐
│                                                               │
│      为屏幕挑一张喜欢的风景                                    │
│      搜壁纸、颜色或关键词  [________________________] [搜索]   │
│      热门分类：风景  插画  极简  动物  城市                     │
│                                                               │
│      精选画廊：按原图比例排列的响应式瀑布流                     │
│      图片上仅悬停显示轻量名称和可用操作                         │
└───────────────────────────────────────────────────────────────┘
```

- 顶部公开导航包含首页、分类/搜索、创建入口和账号入口；桌面不显示当前固定侧栏，移动端使用折叠菜单。
- 首页使用真实图片及其比例排列，优先展示图片；搜索、分类和标签在滚动时仍易访问。
- 无图片时展示简洁品牌空状态与可执行的搜索/上传入口，不展示示例壁纸。
- 分页和筛选继续使用现有接口，不重写搜索逻辑。

### 图片详情

- 桌面采用大图画布与侧边信息/操作面板；移动端改为纵向布局。
- 下载作为主要按钮，分享、编辑、删除仅在现有权限允许时出现。
- 尺寸、比例、格式、大小和主色以清楚的元信息分组显示。

### 登录与注册

- 使用独立的品牌入口布局，主标题与汇图标识明确；表单宽度适中，说明和错误提示清楚。
- 登录、注册与找回入口沿用当前支持的业务路径，不引入新认证功能。

### 空间与操作页面

- 登录后工作区采用紧凑导航与统一内容容器；个人空间、团队空间详情、成员管理和空间分析共享导航与页头。
- 上传、批量导入、批量编辑、图片搜索与扩图表单统一字段间距、按钮和进度状态。
- 图表和配额卡片统一颜色语义，避免装饰性数据或虚构统计。

### 管理页面

- 用户、图片、空间管理继续使用表格，但重新设计页面标题、筛选条、状态标签、分页、空状态和危险操作确认区域。
- 管理页密度高于公开图库；在窄屏允许横向滚动数据表，避免压缩关键信息。

## 品牌清理范围

- 将首页、详情、登录/注册、空间、管理、弹窗和页脚中的产品名称统一为“汇图壁纸网”。
- 移除旧的编程导航菜单、页脚和创建空间页面中的推广链接与署名。
- 移除前端源文件中旧作者品牌注释；更新前端 README 与 package/lockfile 名称。
- 用新的本地 SVG 品牌图标替换旧 PNG 标志，更新 `index.html` 的 title、description 与 favicon。
- 移除分享弹窗里指向旧品牌域名的默认地址，使用当前站点地址和用户生成的分享链接。
- 保留后端 Java 包名、数据库名、API 请求路径和历史项目来源说明之外的非界面技术实现；不删除业务逻辑。

## 验收标准

- 前端运行时、源码、说明和页面元信息中不再有旧品牌名称、旧推广链接或旧标志。
- 首页在桌面与手机宽度上优先展示真实图片；没有内容时空状态完整且无虚构测试数据。
- 图片详情、登录/注册、上传、空间、批量表单、分析和管理员表格都采用共享样式且没有遮挡或溢出。
- 现有导航、搜索、分享、下载、编辑、删除、上传、批量编辑、权限显隐和管理员功能仍调用原有业务接口。
- TypeScript 检查与前端生产构建通过；在浏览器验证首页、登录页、详情布局和至少一个工作区/管理页。

## 实现留给后续计划

确认本稿后，再生成按公共布局、品牌与视觉基础、页面迁移、响应式和验证拆分的实现计划。所有样式改造沿用 Vue 3 与 Ant Design Vue，不添加新依赖。需要真实登录态的批量编辑、扩图操作在用户登录本地站点后验证；不得创建临时账号或虚构图库数据。
